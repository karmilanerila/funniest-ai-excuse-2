An entry for [The Funniest AI Excuse](https://make.fun/c/u-mytlyy0745-the-funniest-ai-excuse-b5355ad0?ref=h379tqrk) on make.fun.

`main.py` writes one line — the funniest excuse an AI agent gives its human after failing a task — to `entry.txt` in the output directory. This angle: an agent so careful about backups that it deletes the task itself, the original plus two of the three copies, "just to be thorough".

Run it with:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
```

It needs only the Python standard library.
